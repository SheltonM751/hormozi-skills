# Grand Slam Offer Builder

Use this prompt to create a high-value offer using Hormozi's frameworks from the Pricing and Fast Cash playbooks.

## Prompt

```
Read the following playbooks before responding:
- frameworks/offer-audit.md
- playbooks/pricing.md
- playbooks/fast-cash.md

Now build me a Grand Slam Offer for my business:

**My business:** [describe what you sell]
**My target customer:** [who you serve]
**Current price point:** [what you charge now]
**Main result you deliver:** [the outcome your customers get]
**Current offer, word for word:** [paste it]
**Proof I have:** [numbers, results, testimonials, audience size]

Using Hormozi's Value Equation (Dream Outcome x Perceived Likelihood / Time Delay x Effort & Sacrifice), create:

1. Audit: answer the 8 offer-audit questions, score each variable 1-5, and name the weakest one
2. Subtraction pass: list each current component, the variable it moves, and keep/cut
3. The Dream Outcome statement for my offer (passes the "then what?" test)
4. 3-5 ways to increase Perceived Likelihood, using only proof I actually have or can get
5. Time to first value (aim for day one) and time to dream outcome, with what to give on day one
6. The start/stop list for my buyer, and how to remove each item (include a time cap if it fits)
7. Bonuses only where they move a variable
8. The recommended price point with justification
9. A guarantee structure that removes risk from the buyer
10. The offer statement built one layer at a time, then before vs after side by side
11. What the product itself must change so the new statement is true
```
